## Project Summary

Syndicati Java is the desktop companion application for the Syndicati residential management platform. It provides a native interface for residents, syndics, and administrators to access residences, apartments, events, forum discussions, messaging, profile features, security tools, and management dashboards.

The application uses JavaFX for the interface, MySQL for shared data, ImageKit for media, Infisical for configuration, and several supporting services for AI, mail, camera-based authentication, voice features, observability, and document generation.
